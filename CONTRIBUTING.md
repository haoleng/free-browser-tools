# Contributing

Thanks for helping keep this list useful.

- The tool must be **free to use in a browser** (no mandatory desktop install or account).
- One line per tool: `- [Name](url) 🔒 — short description.`
  - Use the 🔒 marker only when processing is **client-side** (in the browser).
- Put the entry in the most relevant section, roughly alphabetical, and avoid duplicates.
- No paid placements, affiliate links, or spammy "submit to 500 directories" listings.
- Keep descriptions factual and short (one sentence).

Open a PR with a short rationale. By contributing you agree your changes are released under CC0 1.0.

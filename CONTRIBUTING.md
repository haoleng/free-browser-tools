# Contributing

- The tool must be free to use in a browser.
- One line per tool: `- [Name](url) 🔒 — short description.`
- 🔒 only when processing is client-side. Relevant section, roughly alphabetical, no duplicates.
- No paid placements, affiliate links or spammy directories.

By contributing you agree your changes are released under CC0-1.0.

# Free Browser Tools

A curated list of **free, browser-based tools** — utilities you can open in a tab without installing desktop software or creating an account. Focus on *local-first / client-side* tools that process data in your browser and never upload your files.

> 🔒 = processes data **client-side** (in your browser). Best-effort hint — check the tool's policy before feeding it sensitive data.

Contributions welcome — see [Contributing](#contributing).

## JSON & Data

- [JSONLint](https://jsonlint.com) — Validate and reformat JSON.
- [JSON Crack](https://jsoncrack.com) 🔒 — Visualize JSON/CSV as interactive graphs.
- [jq Play](https://jqplay.org) 🔒 — Online playground for the `jq` JSON processor.
- [CodeBeautify](https://codebeautify.org) — Formatters and converters for JSON, XML, YAML, CSV and more.
- [ConvertCSV](https://www.convertcsv.com) — Convert between CSV, JSON, XML, SQL, Excel and HTML tables.
- [csvjson](https://csvjson.com) — CSV ↔ JSON, JSON to SQL, and more.
- [JSON Viewer](https://jsonviewer.stack.hu) 🔒 — Tree/text viewer with formatting.
- [Olutil JSON Tools](https://json.olutil.com/) 🔒 — Free browser-based JSON toolkit: format, validate, minify, convert (YAML/CSV/XML/properties), JSONPath, JWT and Base64. Runs entirely client-side; no uploads, no sign-up.

## PDF

- [PDF24 Tools](https://tools.pdf24.org) — Large set of free PDF utilities.
- [Sejda](https://www.sejda.com) — Edit, merge, split, compress PDFs.
- [Smallpdf](https://smallpdf.com) — Popular all-in-one PDF suite.
- [iLovePDF](https://www.ilovepdf.com) — Merge, split, compress, convert PDFs.
- [PDF Toolbox](https://pdftoolbox.tech) 🔒 — Client-side compress/merge/split/convert.
- [SimplePDF](https://simplepdf.eu) 🔒 — Browser PDF editor and form filler.
- [pdf.js](https://mozilla.github.io/pdf.js/) 🔒 — Mozilla's open-source PDF viewer.
- [Olutil PDF Tools](https://pdf.olutil.com/) 🔒 — Free browser-based PDF tools: merge, split, compress, convert, remove watermark and more. Everything runs client-side; no uploads, no sign-up.
